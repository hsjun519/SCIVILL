## 접속과 데이터 보관

사용자 선택에 따라 링크를 아는 누구나 로그인 없이 볼 수 있습니다. 링크는 재전달할 수 있습니다. noindex/nofollow와 robots 차단은 검색 수집을 억제하는 설정이며 접근 권한 장치는 아닙니다. 공개 GitHub 소스와 GitHub Pages 주소는 발견될 수 있습니다.

원본 SQLite DB, 검토 후보, 변경 전후 기록, 소스 설정은 공개 저장소에 올리지 않습니다. 운영 데이터는 Sites 서버의 비공개 Cloudflare D1에 영속 보관합니다. 공개 API는 검증·게시된 대회와 집계된 운영 상태만 반환합니다. 관리자 API는 Sites가 검증한 소유자 ChatGPT 계정만 허용하고, 변경 요청은 동일 출처의 JSON POST만 받습니다. 관리자 ID 최초 등록은 소유자만 접속 가능한 상태에서 완료했고, 등록 기능은 공유 전에 비활성화합니다.

D1의 CyvilState에는 대회, 출처, 실행 이력, 검증 결과·근거, 추천에 필요한 설정, 변경 이력, 소유자 권한이 저장됩니다. 단일 원자적 비교·교환 저장으로 관리자 수정과 수집 결과의 덮어쓰기를 방지합니다. 후보 최대 500건, 상태 JSON 약 1.8MB 제한, 최근 작업·변경 30건을 유지하는 소규모 운영 구성입니다. 더 큰 운영에는 개별 관계형 테이블과 별도 백업·보존 정책 확장이 필요합니다.

## 매일 오전 8시 실행

.github/workflows/cyvil-daily.yml의 cron `0 23 * * *`는 UTC 23시, 다음 날 한국 시간 08시입니다. GitHub의 예약 큐로 지연될 수 있습니다. 기본 브랜치에 일정이 있으며 60일 동안 저장소 활동이 없으면 GitHub가 예약 실행을 중지할 수 있으므로 운영자가 Actions 상태를 확인해야 합니다.

워크플로는 contents:read와 id-token:write만 사용합니다. GitHub OIDC의 서명·발급자·대상·저장소 ID·소유자 ID·main 브랜치·정확한 워크플로 경로·만료 시각을 서버에서 검증합니다. 비밀키를 저장소에 넣지 않습니다. 실행 중에만 HTTPS로 비공개 수집 문맥을 받아 임시 SQLite로 규칙을 적용하고 결과를 D1에 저장합니다. DB·후보 파일을 커밋하거나 Actions 아티팩트로 업로드하지 않습니다. 임시 디렉터리는 작업 후 삭제됩니다.

순서: 32개 테스트 → 인증된 문맥 조회 → 출처별 robots와 HTTPS 허용 호스트·공인 IP 확인 → 요청 간격·타임아웃·재시도 적용 → 후보 수집·중복 제거 → 공식 근거·참가자격·기간 검사 → 검토/게시 분리 → 기존 공고 일정 재검증 → 인증된 결과 저장. 일상 실행에서 LLM/API 호출은 0회입니다. AI라는 단어가 있는 대회 공고 수집과 AI 서비스 호출은 별개입니다.

성공한 첫 실제 GitHub 실행 뒤에만 활성 상태를 표시합니다. 출처 실패는 partial로 기록하고 작업을 실패 처리하며, 기존 대회를 삭제하지 않습니다. 메타데이터 확인 성공을 모든 후보의 검증 성공으로 표시하지 않습니다. 수동 실행은 GitHub Actions의 Run workflow 버튼을 사용합니다.

## 게시·추천 규칙

고등학생, 초중고 또는 연령 제한 없음이 공식 참가 자격에 명시되어야 합니다. 일반적인 누구나·청소년만으로는 자동 확정하지 않습니다. 지역·나이·보유 장비 등의 조건은 조건부 검토, 대학생 전용·사업자 필수는 제외합니다. 제목, 주최, 시작일, 종료일, 참가자격, HTTPS 공식 링크 및 자격·일정 근거가 필수입니다. 충돌 정보는 검토함으로 보냅니다. 관리자의 승인 버튼도 검사를 우회하지 않습니다.

장관상은 후원 부처 이름이 아니라 공식 시상 문구와 근거로 판정합니다. 포스터에 AI 주제가 등장하는 것만으로 소프트웨어로 분류하지 않습니다. 점수는 학생·동아리 30, 분야 25, 공식 출처 20, 탐구·제작 15, 준비 기간 10점입니다. 장관상 → 공학 → 소프트웨어 → 기타·환경 순으로 분야별 최대 3개, 전체 중복 없이 추천하며 빈 분야를 억지로 채우지 않습니다. 고정은 필수 검증 조건과 마감 검사를 우회하지 않습니다.

서버 조회 시와 화면의 15초 주기에서 한국 시간 마감을 계산합니다. 정확한 시각이 없으면 마감일 23:59:59.999 KST로 잠정 처리하며 시각 미확인을 표시합니다. 종료된 대회는 추천에서 빠지고 지난 대회에 남습니다. 날짜 연장은 전용 공식 파서가 반영하고, 자격·시상 구조가 바뀌면 검토로 돌립니다. URL 정규화+회차 시작일, 정규화 제목·주최·연도를 함께 사용해 중복과 연도별 공고를 구분합니다.

## 관리자 사용

관리자 화면에서 후보와 불확실한 이유·근거·점수를 보고 정보 수정, 수동 등록, 검증 후 승인, 숨김, 추천 고정·제외, 출처 활성/중지, 실행·변경 이력 확인이 가능합니다. 자료가 없는 필드는 null로 두며 확인 필요로 표시합니다. 공식 검증 근거를 수동 입력할 때 원문을 대조해야 합니다.

## 기존 기능과 현재 한계

대회는 모든 방문자가 같은 서버 데이터를 조회합니다. 기존 팀 모집·지원·프로젝트·일정·개인 관심 목록은 기기 체험 기능입니다. 다른 기기와 공유되는 회원·팀·지원서 DB는 연결하지 않았습니다. 실제 지원서가 전송되거나 공동 편집이 된다고 안내하지 않습니다. 기존 기록은 마감 후에도 유지됩니다.

현재 소규모 허용 출처에만 어댑터가 있어 모든 대회 사이트를 포괄하지 않습니다. 공식 정보가 불충분한 신규 후보는 관리자가 확인해야 합니다. 별도 외부 알림·이메일 발송·유료 서비스·자동 결제는 연결하지 않았습니다.

## 검증과 비용

Python: `python -m unittest discover -s tests -v` (32개). 실제 HTTP 인증/승인 차단, 참가자격, 시상 근거, 기간 경계, 중복, 연간 회차, 연장, 실패 시 보존, URL 안전성, cron 변환, AI 호스트 미포함을 검사합니다. 서버 규칙과 OIDC 서명 검증도 Node 테스트 및 배포 후 HTTP 응답으로 확인합니다.

AI 런타임 비용은 없습니다. GitHub 공개 저장소 표준 Actions/Pages는 공식 무료 범위 내 사용이며, Sites/D1은 현재 계정의 제공 한도와 정책을 따릅니다. 무제한 무료 운영을 보장하지 않으며 유료 플랜을 가입하지 않았습니다.
